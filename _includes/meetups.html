{%- comment -%} The single source of truth for "which meetups are upcoming". A meetup counts as upcoming through the end of its own calendar day, so we compare YYYYMMDD as integers rather than raw timestamps. "Now" is build time (site.time); the footer prints the build date so a stale page is self-evident. The clock is rolled back 7 hours before the build date is taken. Posts carry a bare date (midnight), but meetings run 19:00-22:00 Mountain, and the builder's clock may be UTC (GitHub Pages) or Mountain (a laptop). The shift keeps a meeting listed through its own evening under either clock. It errs by listing a meetup for a few hours past midnight, which is the harmless direction — a meeting must never vanish from the front page while it is still happening. NOTE: Liquid has no array-append filter (`push` does not exist and silently yields nil), so the split is done with plain loops over site.posts instead of building two arrays. site.posts is newest-first, so `reverse` gives ascending order. Params: show "upcoming" (default) — upcoming only, falling back to the last meeting held. "both" — upcoming (no fallback) plus one page of past meetings. "past" — one page of past meetings only. page which page of the past list to render (1-based). Only read for "both"/"past". The past list is paginated `site.paginate` at a time. It slices the past posts itself rather than using `paginator.posts`, which counts upcoming meetups too and would leave page 1 short; jekyll-paginate only exists here to generate the extra page files. That means the pager can link a page the plugin did not generate if the two counts ever disagree by a whole page — they cannot, because the plugin always pages over at least as many posts as this does. {%- endcomment -%} {%- assign today = site.time | date: '%s' | minus: 25200 | date: '%Y%m%d' | plus: 0 -%} {%- assign chrono = site.posts | reverse -%} {%- if include.show != "past" -%} {%- assign upcoming_count = 0 -%} {%- for post in chrono -%} {%- assign day = post.date | date: '%Y%m%d' | plus: 0 -%} {%- if day >= today -%}{%- assign upcoming_count = upcoming_count | plus: 1 -%}{%- endif -%} {%- endfor -%}
